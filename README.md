# ULTRA PRO KING NUMBER — iOS starter

This is a new SwiftUI starter project, not a converted Android APK or a verified replica of the original app.

## Included
- Dark SwiftUI interface with crown branding
- Mobile-number and OTP login screen layout
- Home dashboard, history and profile tabs
- Placeholders for the original service and data

## Important
- OTP sending and verification are not implemented. Connect only the owner's authorized OTP provider/API.
- Live numbers, payments, account data and admin tools are not inferred or fabricated.
- No credentials, API keys, certificates or provisioning profiles are included.
- Visual/functional parity requires authorized screenshots and the original backend/API contract.

## Build unsigned IPA
1. Open Actions in this repository.
2. Run Build unsigned iOS IPA, or push a commit to main.
3. Download the unsigned-ipa artifact from the completed workflow run.

The artifact is unsigned. It needs a valid Apple certificate and provisioning profile before installation. GBox compatibility depends on its current version and certificate/profile compatibility.
